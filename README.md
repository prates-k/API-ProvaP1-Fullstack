# 🚀 API de Produtos e Categorias

> **Avaliação Presencial — Laboratório de Programação FullStack**  
> RESTful API construída com **Spring Boot 3.x**, validação de dados com **Bean Validation**, tratamento global de exceções e persistência em memória.

---

## 🛠️ Tecnologias Utilizadas

* **Java 17**
* **Spring Boot 3.2.3**
    * `spring-boot-starter-web`
    * `spring-boot-starter-validation`
* **Apache Maven**

---

## ⚙️ Como Executar a Aplicação

### Pré-requisitos
* Java 17+ instalado
* Maven 3.8+ (ou utilize o wrapper `./mvnw` incluído no projeto)

### Passo a Passo

1. **Clonar/Descompactar o projeto** e navegar até o diretório raiz:
   ```bash
   cd provap1-fullstack

Executar a aplicação:

```bash
   ./mvnw spring-boot:run
```

(Caso esteja no Windows Command Prompt, utilize mvnw.cmd spring-boot:run)

A API estará disponível em: http://localhost:8080
